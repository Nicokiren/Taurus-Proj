# Projeto Taurus

Este projeto foi desenvolvido como parte do nosso aprendizado em desenvolvimento de software com C#, ASP.NET Core e Entity Framework.

## 📌 Descrição

O Taurus é uma aplicação web que permite o gerenciamento de serviços. O sistema foi construído utilizando o padrão MVC, com banco de dados MySQL e integração com Entity Framework Core.

## 🚀 Tecnologias Utilizadas

- C#
- ASP.NET Core MVC
- Entity Framework Core
- MySQL
- Visual Studio / VS Code

## 📂 Estrutura do Projeto

- `Models/` - Contém as classes de modelo da aplicação
- `Data/` - Contém o contexto do banco de dados (AppDbContext)
- `Controller/` - Contém os controladores da aplicação (ex: ServicosController)
- `Views/` - Contém as views (interface) associadas aos controladores
- `wwwroot/` - Contém os arquivos estáticos (CSS, JS, imagens)
